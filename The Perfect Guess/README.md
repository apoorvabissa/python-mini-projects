# 🔢 The Perfect Guess

A simple number guessing game built with Python where the player tries to guess a randomly generated number between **1 and 100**.

This project was created while learning Python fundamentals through the **CodeWithHarry Python course**.

## 📌 About the Game

The computer randomly generates a number between **1 and 100**.

The player keeps entering guesses until they find the correct number.

After every incorrect guess, the program provides a hint:

* **"Higher number please"** → when the guess is too low
* **"Lower number please"** → when the guess is too high

Once the correct number is guessed, the program displays the total number of attempts.

## ✨ Features

* Random number generation
* Interactive command-line gameplay
* Higher/lower hints
* Attempt counter
* Simple and beginner-friendly implementation

## 🛠️ Technologies Used

* **Python 3**
* `random` module
